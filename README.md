# IDEA — Dispatch Edition

A press-wire redesign concept for the [IDEA Uganda](https://ideaug.org/) homepage (Innovations for Democratic Engagement and Action), built strictly on the site's own brand colors (`#BA2025` red / `#1E1E1E` ink) and its Roboto / Roboto Slab typefaces.

Live: https://gfreedoms.github.io/idea-dispatch-edition/

## What's here

A single self-contained `index.html` (fonts inlined, no build step) plus the image assets it references. Static site — open `index.html` directly or serve the folder with any static host.

## Notes

- This is a design concept / mockup, not affiliated with or published by IDEA.
- Navigation routes between a real homepage and placeholder "design coming soon" pages for the rest of the site's structure (About Us, What We Do + its four programmes, Current Projects, Publications, Blog, Contact Us) via a lightweight hash router in `index.html`.
